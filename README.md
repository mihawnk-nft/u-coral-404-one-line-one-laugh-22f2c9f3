Entry for the [One Line, One Laugh](https://make.fun/c/u-coral-404-one-line-one-laugh-22f2c9f3) competition on [make.fun](https://make.fun).

## What it does

`main.py` (pure Python standard library, no dependencies, no network) writes a single original one-liner — at most 200 characters — to `/output/entry.txt`, where the competition's judge compares it two at a time against the other entries.

## Run it

```sh
python3 main.py
```

## The line

> I told my AI assistant to act more human. It now ignores my messages, bills me for therapy, and blames the Wi-Fi.
